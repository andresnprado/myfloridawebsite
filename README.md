# MyFlorida Parody Site

A satirical, static recreation of the MyFlorida.gov state portal, built with HTML, CSS and Bootstrap.

> **Disclaimer:** This is a parody made for fun and practice. It is not affiliated with, endorsed by, or connected to the State of Florida or any state agency. For real state services, visit [myflorida.com](https://www.myflorida.com).

## Features
- Bootstrap layout modeled on the state portal
- "Florida Man" themed content and humorous menu items
- A client-side password prompt on page load (a gag, not real security)
- Links to real Florida public resources (DMV, reemployment, child support, taxes)
- Google Translate widget

## Running it
No build step. Clone the repo and open `myflorida.html` in a browser.

## Built with
HTML, CSS, Bootstrap, Fontello icons, Google Fonts (Catamaran, Bilbo Swash Caps)
